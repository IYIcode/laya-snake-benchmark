## 四、重建命令（按顺序）

```powershell
python _dev\make_audio4.py        # 1. 配音（+20%）：_ppt_audio4/q01..q09 + lane/L00..L06，并写 lane_timeline.json
python _dev\make_qr.py            # 2. 邀请二维码：_ppt_imgs/qoder_qr.png + _ppt_video4/qoder_qr_135.png
python _dev\render_slide6.py      # 3. 考场页棋盘动画 472 帧 → slide6_v.mp4（约 10s）
python _dev\render_lane.py        # 4. 五路同屏 581 帧 → _ppt_video4/lane_frames/（约 30s）
python _dev\build_lane_clip.py    # 5. 编 lane_v.mp4 + lane_a.wav（旁白含前置留白/句间停顿/末尾定格）
python _dev\render_slide17.py     # 6. 把二维码合成进第 17 页 → slide17_invite.png
python _dev\build_video4.py       # 7. 十段逐个编码 → 拼接 → laya-ppt-3分钟.mp4（首次运行自动备份旧片）
```

预览单帧（不建帧目录）：

```powershell
python _dev\render_lane.py --preview 5.0,11.5,17.5,22.8     # → _dev/lane_preview_*.png
python _dev\render_slide6.py --preview 3,10,17              # → _dev/slide6_preview_*.png
```

调参位置：

- 旁白文案 / 句间停顿：`_dev/lane_config.py`（`PIECES` / `LEAD` / `PAUSE` / `TAIL`）
- 赛道速度、面板文案、字幕：`_dev/render_lane.py`（`STEP_FRAMES` / `ZS_STEP_F` / `CAPTIONS`）
- 考场页步速：`_dev/render_slide6.py`（`STEP_S = 0.150`，与 HTML 的 `setInterval` 一致）
- 段间停顿与段落顺序：`_dev/build_video4.py`（`GAP` / `MAP`）

我们花了一周时间测试开源决策模型 Laya：从网页动画到真实模型、从提示词到六种训练方法、再到纯代码小程序——最后让它们全部同台跑同一条食物序列，看谁得分最高。本页所有数字均为本机实测。

① 为什么测试 Laya决策模型 ≠ 聊天模型

2026 年 9 月中，TypeSafe 的 Jev 刷屏（"不聊天，直接做决策"）：输入状态 + 带说明的候选项，一次前向并行输出每个选项的概率，单步 ~30ms。Laya（421M ModernBERT，开源）是同一范式的开源实现，当天冲上 HuggingFace 趋势第一。

问题：它开箱到底多强？要喂什么才能干活？贪吃蛇是理想的试金石——规则一句话讲清、生死判定无歧义、得分可精确比较、纯代码算法有明确的"天花板"可对照。

② 演进路线从没有实测的网页 PPT，到跑赢老师的调参小抄 —— 每一步都是实测数字

5 · 小抄六轮调参（不动权重）

59.8 食物/局

只改喂给模型的数字：入袋罚分→两拍前瞻空间（用户"下下步"设想）→安全免罚。59.8 反超 BFS 老师(~53)。同期实测：自然语言规则附注=完全无效（结果逐字节相同）——模型只读训练过的数字通道。

44.2 食物/局

把 144 格编成一条闭合环，状态带环距离、选项带环步数（坐标事实，不透露答案）；纯代码环老师 6/6 局 141 通关产标签，限时 CE 微调 800 步/52 分钟 → 44.2，8 局中 3 局 6000 步仍存活。

7 · 环契约 + 提示词动作掩码

141 = 通关

不改权重、不喂答案：只在选项文本前加 BLOCKED: 屏蔽"会破坏哈密顿环不变量／撞墙撞身"的方向（模型仍看不到哪格是食物），桥接端把被屏蔽项概率清零重归一 → 训练过的环模型被迫只在环安全方向里挑，裸分 44.2 的模型被同一句提示词推到 141 通关（4/4 局通关，seed 1000–1003；最快 141 食物 / 4623 步 / 167 秒）。约一半的步长里有 ≥2 个环安全方向可选（multiLegal 45–51%）——掩码没把蛇锁进唯一通道，选择权仍真归模型。右侧竞技场"环契约·掩码通关"赛道即此逻辑，与纯代码环保险同一食物序列。

8 · 纯提示词 · 报错账通关（零掩码）

3/3 种子 141 通关

把掩码全部拿走，状态里只喂一个数字 jumpCount（报错账：本局你已经几次跳过自己身体），规则只说一句"目标：以 jumpCount = 0 收场"。模型自己收敛：离线 seed 1000-1002 三局全部 141 通关（含此前所有配方都输掉的种子，以及一局 0 次违规的完美局），守规率 100%、0 次代码干预；扩测到 9 个种子 4 胜，剩下的败局全部集中在同一个结构性盲点帧（尾格诱饵），提示词路线的天花板约五成——再往上要动权重。同轮还测出两条硬边界：① 规则文字 5 种改写（全程铁律/死亡框架/删光尾注…）输出逐字节不变——文字不动模型，状态里的数字才动；② 同一提示词喂给未训练底模 = 0 分 2 步死，追加"安全方向清单"甚至"正确答案"仍 0 分——提示词不是能力，是能力的开关。右侧竞技场「纯提示词·报错账」道即此逻辑，照录 seed1002 通关局食物序列重放，全程无保护。

⑤ 结论蛇是磨刀石，不是主场

同台结论（本页竞技场实测）：没训练的 Laya 连棋盘都读不动（0 分撞墙）；给它特征小抄 + 训练才能干活（19.95 → 44.2 → 59.8）；而同一个任务，100 行纯代码小程序拿 141 通关——在规则明确的小任务上，决策模型打不过手写算法，甚至逊色。

但"提示词"确实能把训练过的模型推上牌桌：对没训练的底模，任何提示词都救不了（6 组合规改写全 0 分，纯掩码只剩均匀随机）；可对训练过的环契约模型，只在提示里加一句 BLOCKED: 动作掩码（不喂答案、不动权重），裸分 44.2 立刻被顶到 141 通关。结论：决策模型的能力天花板由训练决定，提示词／动作掩码负责把这份能力"逼"到临界点上——两者缺一不可。

再往深一层：不替它算，让它自己醒（本页实测第 8 道，零掩码）。把动作掩码全部拿走，状态里只喂一个数字——报错账 jumpCount：本局你已经几次跳过自己身体——规则只说"目标：以 0 次报错收场"。同一个模型、前 3 个种子 3 局全部自己吃到 141 通关（含此前所有配方都输掉的种子，和一局 0 违规的完美局），扩测 9 局 4 胜，全程 0 次代码救援。这一轮同时划出提示词的两条硬边界：其一，规则文字 5 种改写（全程铁律、死亡框架、甚至删光全部尾注）输出逐字节不变——文字不动模型，状态里的数字通道才动它；其二，同一份提示词喂给未训练的底模 = 0 分、2 步撞死，把"安全方向清单"乃至"正确答案"直接写进提示里，仍然 0 分——提示词不是能力，是能力的开关。理解不是激发不出来，是要用它的语言说，而且它得先学过这门语言。

那它的价值在哪？通用场景：状态能用文字描述、动作是离散选项、不存在可手写的算法、需要毫秒级高并发。Jev 官方宣传的"快 193.6 倍 / 便宜 444.6 倍"，对比的是"拿通用大语言模型当决策器"，不是对比手写算法。这类模型要靠足够多的训练（公司级 RL）才能达到人的一般水平——我们的贪吃蛇实验恰好完整复现了这条学习曲线：0.0 裸模型 → 19.95 喂标签 → 40.8 自我进化 → 59.8 喂对特征后反超老师。

举个正经用途的例子：整治游戏公屏

游戏公屏每秒刷出大量消息，要识别卖片广告、卖挂、粗口辱骂等不适言论并给出处置。这正是 Laya 范式的主场：输入 = 一条消息 + 上下文事实（发言者历史处罚次数、所在频道），候选项 = 处置动作，输出 = 各动作概率，单条 ~30ms、可并行、规则用文字随时改、新出现的黑话用少量标注微调即可——不需要链式推理，也不需要为每种违规手写正则。

一句话总结：Laya 这类决策模型不是"更小的 ChatGPT"，而是"把判断做成一次完形填空"的新范式——裸模型什么也不会，喂对特征+训练才及格，在它的主场（通用、高频、无算法可写）才是它的时代。

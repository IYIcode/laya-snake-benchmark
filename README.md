# 用一条贪吃蛇，实测开源决策小模型 Laya

> Jev 的平替 Laya，到底能不能干活？—— 12×12 贪吃蛇考场 · 六级演进 · 全部数字来自真跑日志

这是一个**可验证**的实测项目：所有结论背后都有原始档案，页面可以直接在浏览器里复跑。
配套视频已发布，本仓库是它的证据与复现入口。

---

## 一句话结论

**Laya 训练后能干活，但要摆对位置：程序管感知和兜底，模型管高频选择。**

它能：吃透一套契约、反超教学算法、提示词加持下 141 通关、约 30ms/次、约 1GB 显存可端侧。
它不能：裸感知（0/1/2/3 数字阵零样本 23 局全 0 分）、通用理解（不如闭源大训练量的 Jev），智力就是"选择题选手"。

## 三个可交互页面（浏览器直接跑，不用装任何东西）

用本地服务器打开（页面要通过 `fetch` 读档案 JSON，直接双击 `file://` 会被浏览器拦住）：

```bash
python -m http.server 8895
# 然后打开
# http://127.0.0.1:8895/laya-snake-cockpit.html     ← 主入口：五路选手驾驶舱
# http://127.0.0.1:8895/laya-snake-myrun.html       ← 我本人 4370 步 141 通关局逐手回放
# http://127.0.0.1:8895/laya-snake-theater.html     ← 同台实测剧院
```

| 页面 | 看什么 | 数据来源 |
|---|---|---|
| `laya-snake-cockpit.html` | **五条赛道**：①未训练（实测死亡规律重放）②微调（2026-09-26 桥接日志 400 手原件，290 手可重建蛇身，逐手回放小抄字符串与概率）③环契约+跨身计数（seed1002 通关局 141 格实录食物原序）④环保险算法（**此刻正在真跑**，左边是每步环不等式 PASS/FAIL）⑤我本人（141 真实通关局逐手回放） | `_cockpit_replay.json`、`_jumpfood_1002.json`、`_myrun_data.json` |
| `laya-snake-myrun.html` | 我逐段决策的原始载荷："下一段"能看到我每次问自己时发出的输入原文 | `_myrun_data.json` |
| `laya-snake-theater.html` | 六条赛道的同台对照 | 页内数据 |
| `laya-ppt.html` | 完整 17 页报告（含讲解备注，按 `N` 键打开备注） | `_ppt_imgs/*` |

> 说明：需要模型在线推理的赛道要接本地桥（`laya_bridge.py`），按纪律默认停用；
> 页面里凡是没有逐手档案的部分，都明确标了"示意"，**不用动画冒充推理**。

**没有放进仓库的**：

- 微调后的模型权重与训练中间产物：`_graveyard/`（约 11GB）、`_rlcd/`（约 4GB）
- 视频流水线的中间素材：`_ppt_video/`（各页静态截图）、`_ppt_audio4/`（配音）、`_ppt_video4/`（逐帧 PNG，约 120MB）

- 含本机路径的运行期日志（`finetune.log`、`v3_grid.log`、`bridge*.log` 等，已列入 `.gitignore`）

入库合计约 **84MB**，最大单文件 `_tune_runs/look2.json`（17MB），无需 Git LFS。
需要权重或原始训练日志可以开 issue。

## 这个项目的立场

- **只喂事实，不喂答案**：模型只看到棋盘数字阵与规则文本、落点事实与环距离数字，
  从不把"该走哪"写进选项里。
- **不掩饰失败**：零样本 23 局全 0 分照实写；"透答案给它"最好也只有 5.5 分；
  裸棋盘训练 1 小时只有 44.2。
- **区分"实录"与"示意"**：有逐手档案的逐手回放，没有的明确标注为示意。
- **数字可查**：每个结论都能对应到仓库里的一个文件或一段可运行代码。
